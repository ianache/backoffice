Create the Docker Compose file for local Keycloak + PostgreSQL, and a realm export JSON that Keycloak auto-imports on first start.

`docker-compose.yml`:
```yaml
version: '3.9'
services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: keycloak
      POSTGRES_USER: keycloak
      POSTGRES_PASSWORD: keycloak
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U keycloak"]
      interval: 5s
      timeout: 5s
      retries: 5

  keycloak:
    image: quay.io/keycloak/keycloak:26.0.5
    command: start-dev --import-realm
    environment:
      KC_DB: postgres
      KC_DB_URL: jdbc:postgresql://postgres:5432/keycloak
      KC_DB_USERNAME: keycloak
      KC_DB_PASSWORD: keycloak
      KEYCLOAK_ADMIN: admin
      KEYCLOAK_ADMIN_PASSWORD: admin
      KC_HTTP_PORT: 8080
    volumes:
      - ./keycloak:/opt/keycloak/data/import
    ports:
      - "8080:8080"
    depends_on:
      postgres:
        condition: service_healthy

volumes:
  postgres_data:
```

`keycloak/realm-export.json` — Create a minimal realm export with:
- realm name: `backoffice`
- client: `backoffice-frontend` (public, PKCE enabled, redirect URIs: `http://localhost:5173/*`, web origins: `http://localhost:5173`)
- client: `backoffice-bff` (confidential, service account enabled)
- Realm roles (7 required by PRD §3): `PlatformAdmin`, `TenantOwner`, `TenantAdmin`, `TenantViewer`, `ProductManager`, `ProductDeveloper`, `ProductQA`, `CompanyAdmin`, `CompanyUser`
- Seed user: `admin@backoffice.dev` / password: `Admin1234!` with `PlatformAdmin` realm role assigned
- Realm settings: `accessTokenLifespan: 300` (5 min), `ssoSessionMaxLifespan: 36000` (10 hrs)
- `useRefreshTokens: true`, `refreshTokenMaxReuse: 0`
- IMPORTANT: `lightweightAccessTokenEnabled: false` (per RESEARCH.md pitfall #2 — lightweight tokens strip realm_access.roles)

The realm-export.json format follows Keycloak's standard export format. Key fields:
```json
{
  "realm": "backoffice",
  "enabled": true,
  "clients": [...],
  "roles": { "realm": [...] },
  "users": [...],
  "attributes": {
    "access.token.lifespan": "300"
  }
}
```
