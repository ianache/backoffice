Test AUTH-03 — Get a token for admin@backoffice.dev and call /auth/me:
```bash
# Get access token via Resource Owner Password Credentials (dev only — not for production)
TOKEN=$(curl -sf -X POST \
  "http://localhost:8080/realms/backoffice/protocol/openid-connect/token" \
  -d "client_id=backoffice-frontend" \
  -d "grant_type=password" \
  -d "username=admin@backoffice.dev" \
  -d "password=Admin1234!" \
  | jq -r '.access_token')

echo "Token obtained: $([ -n "$TOKEN" ] && echo YES || echo NO)"

RESPONSE=$(curl -sf -H "Authorization: Bearer $TOKEN" http://localhost:3000/auth/me)
echo "AUTH-03 /auth/me response: $RESPONSE"
echo "$RESPONSE" | jq '.roles' | grep -q "PlatformAdmin" \
  && echo "AUTH-03 roles OK" || echo "AUTH-03 FAIL - PlatformAdmin not in roles"
```

Note: The Resource Owner Password grant is used here only for automated testing. Disable it in the Keycloak client settings before production deployment.

Report all test results before the human checkpoint.
