# Phase 2.1: UI System & Brand Alignment - Context

**Gathered**: 2026-06-07
**Status**: Initial Research

<domain>
## Phase Boundary
Align the application's visual system with the Google Stitch design system and implement a robust theme system supporting Light and Dark modes. This phase acts as a bridge between the functional foundations and a polished, production-ready interface.
</domain>

<decisions>
## Implementation Decisions

### Design System
- Reference Google Stitch designs in: https://stitch.withgoogle.com/u/1/projects/5651761190718398526
- Adhere to typography, spacing, and color palettes defined in Stitch.

### Theme System
- Implement CSS variables for all design tokens (colors, spacing, shadows).
- Toggle Light/Dark mode via a switch in the main navigation bar.
- Toggle position: Left-aligned in the navbar, preceding existing icons.
- Persistence: Store theme preference in `localStorage`.
- Support system preference detection (`prefers-color-scheme`).

</decisions>
