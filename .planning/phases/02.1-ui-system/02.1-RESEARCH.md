# Phase 2.1: UI System & Brand Alignment - Research

**Researched**: 2026-06-07
**Domain**: UI Design Tokens / CSS Variables / Theme Toggling in Vue 3
**Confidence**: HIGH

## Summary
The portal currently uses basic Vanilla CSS. To support both Google Stitch alignment and dynamic theme switching, we must transition to a **Design Token** approach using CSS variables. 

The light/dark mode implementation requires:
1. A `:root` or `.light-mode` / `.dark-mode` class-based variable system.
2. A Pinia store (or App-level state) to manage the current theme.
3. Updating the global styles to use these variables for colors, backgrounds, and text.

## Stitch System
- The Stitch link provides detailed specs for spacing (8px grid), standard component behavior, and brand colors.
- We should extract key variables (primary, surface, error, success) for both modes.

## Theme Toggle
- The toggle should be an interactive component (e.g., Sun/Moon icon button).
- Position: Navbar, left side, before other actions.
