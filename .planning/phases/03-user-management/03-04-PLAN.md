**UserTable.vue**

Mirror TenantTable.vue structure. Props: `users: KcUser[]`, `isLoading: boolean`. Emits: `edit(user: KcUser)`, `disable(user: KcUser)`, `enable(user: KcUser)`, `reset-mfa(user: KcUser)`.

Toolbar: "All Members" label, filter chips (all / active / inactive), density toggle button (compact icon).

Table columns: User (avatar + name + email stacked), Role (badge), Status (dot + label), Actions (edit icon only — context menu for disable/enable/reset-mfa).

Avatar: `<div class="w-10 h-10 rounded-full bg-secondary-container flex items-center justify-center text-on-secondary-container font-bold text-sm">{{ initials(user) }}</div>` where `initials` returns first letter of firstName + first letter of lastName, uppercase.

Role badge colors (Tailwind classes):
- TenantOwner: `bg-primary/10 text-primary`
- TenantAdmin: `bg-primary/10 text-primary`
- TenantViewer: `bg-outline-variant/40 text-on-surface-variant`
- ProductManager: `bg-secondary/10 text-secondary`
- ProductDeveloper: `bg-secondary/10 text-secondary`
- ProductQA: `bg-secondary/10 text-secondary`
- null/empty: `bg-outline-variant/40 text-on-surface-variant` with label "No role"

Status indicator: colored dot (`w-2 h-2 rounded-full`) + text label.
- enabled=true: `bg-green-500` dot + "Active" text
- enabled=false: `bg-neutral-400` dot + "Inactive" text

Actions: An edit icon button (`pencil` or `edit` material symbol) that emits `edit(user)`. For disable/enable/reset-mfa, use `md-menu` pattern from TenantTable with `positioning="popover"` (critical — avoids invisible menu in overflow:hidden table — per Phase 06-04 decision).

Empty state: if no users and not loading, show centered "No members yet" message.
Loading state: skeleton rows or spinner while isLoading is true.

Compact mode: when `isCompact=true`, reduce row padding from `py-3` to `py-1.5`.

**UserDrawer.vue**

Props: `show: boolean`, `user: KcUser | null` (null = create mode). Emits: `close`, `save(payload: UserPayload)`.

Title: "Manage Access" (always — whether creating or editing).
Width: `w-[440px]` (per CONTEXT.md spec).

Three tabs using `md-tabs` + `md-primary-tab` (matching TenantDrawer pattern):
1. General — renders `<UserForm v-model="formData" />`
2. Roles — renders `<UserRolesForm v-model="rolesData" />`
3. Activity — renders `<UserActivityTab :user-id="user.id" />` (only when user is not null and tab is active)

Internal state:
- `activeTab: 'general' | 'roles' | 'activity'` — start at 'general'
- `formData: Partial<UserPayload>` — populated from `user` prop when editing, empty for create
- `rolesData: { tenantRole: string; productRoles: Record<string, string> }` — from user when editing

Footer: two buttons — Cancel (outlined, emits close) and Save (StitchButton primary, emits save with merged formData + rolesData). In edit mode show "Save Changes", in create mode show "Invite Member".

Watch `user` prop: when it changes, reset formData and rolesData from the new user's data.

Activity tab: only render UserActivityTab when `show && user && activeTab === 'activity'` to avoid unnecessary API calls.

Use `<Teleport to="body">` for the drawer (z-index issues if not teleported — same as TenantDrawer).

Overlay: semi-transparent backdrop `class="fixed inset-0 bg-black/40 z-40"` on click emits close.

Drawer panel: `class="fixed right-0 top-0 h-full bg-surface-container-lowest shadow-xl z-50 flex flex-col"` with transition slide-in-right.
