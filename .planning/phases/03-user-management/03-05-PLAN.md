
The existing `router.beforeEach` guard already handles role checking via `requiredRoles.some(r => authStore.hasRole(r))` — no changes needed to the guard logic.

**Step B: portal/src/components/layout/MainLayout.vue**

Read the full current file first. Add a Users nav button after the Tenants button, with role guard using `v-if`:

```html
<!-- Users — only for TenantAdmin and TenantOwner -->
<button
  v-if="authStore.hasRole('TenantAdmin') || authStore.hasRole('TenantOwner')"
  @click="router.push('/users')"
  :class="[
    'w-full flex items-center gap-4 px-4 py-2 rounded-lg transition-all duration-200 text-left',
    isActive('/users')
      ? 'bg-primary text-on-primary font-semibold'
      : 'text-on-surface-variant hover:bg-surface-container-high'
  ]"
>
  <span class="material-symbols-outlined text-[22px]">people</span>
  <span class="text-sm">Users</span>
</button>
```

Place this after the Tenants button and before the Products placeholder button.

Note: The Tenants button should also get an explicit `v-if="authStore.hasRole('PlatformAdmin')"` guard if it doesn't already have one — TenantAdmins should not see the Tenants nav item. Check the current file and add if missing.
