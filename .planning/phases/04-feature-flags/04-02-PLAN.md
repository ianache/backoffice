  <name>Hierarchical Flag Evaluation Engine</name>
  <files>backend/tests/test_feature_flags_eval.py, backend/app/domains/feature_flags/service.py</files>
  <behavior>
    Hierarchy tests (FLAG-04):
    - evaluate_flag([global_flag], context_no_match) → bool(global_flag.default_val) when enabled=1
    - evaluate_flag([global_flag, tenant_flag], {'tenant_id': tenant_flag.tenant_id}) → result from tenant_flag (not global)
    - evaluate_flag([global_flag, tenant_flag, product_flag], full_context) → result from product_flag (highest priority)
    - evaluate_flag([], {}) → False
    - evaluate_flag([disabled_global], {'tenant_id': 'X'}) → False (disabled flag returns False)
    - evaluate_flag([global_flag], {}) where global_flag has rules matching user → returns rule.result
    - evaluate_flag([global_flag], {}) where global_flag has rules not matching → returns bool(default_val)

    Operator tests (FLAG-05) — _evaluate_rule:
    - {'operator': 'equals', 'attribute': 'country', 'value': 'PE'} vs {'country': 'PE'} → True
    - {'operator': 'equals', 'attribute': 'country', 'value': 'PE'} vs {'country': 'US'} → False
    - {'operator': 'in', 'attribute': 'country', 'value': ['PE', 'AR']} vs {'country': 'PE'} → True
    - {'operator': 'in', 'attribute': 'country', 'value': ['PE', 'AR']} vs {'country': 'US'} → False
    - {'operator': 'notIn', 'attribute': 'country', 'value': ['US']} vs {'country': 'PE'} → True
    - {'operator': 'notIn', 'attribute': 'country', 'value': ['US']} vs {'country': 'US'} → False
    - {'operator': 'contains', 'attribute': 'email', 'value': '@acme'} vs {'email': 'john@acme.com'} → True
    - {'operator': 'regex', 'attribute': 'email', 'value': '^admin'} vs {'email': 'admin@co.com'} → True
    - {'operator': 'regex', 'attribute': 'email', 'value': '^admin'} vs {'email': 'user@co.com'} → False
    - {'operator': 'unknown_op', ...} → False (no exception)
    - {'operator': 'equals', 'attribute': 'missing_attr', 'value': 'X'} vs {} → False (no KeyError)
  </behavior>
