OPERATORS = {
    "equals":   lambda actual, expected: actual == expected,
    "in":       lambda actual, expected: actual in expected if isinstance(expected, list) else False,
    "notIn":    lambda actual, expected: actual not in expected if isinstance(expected, list) else True,
    "contains": lambda actual, expected: str(expected) in str(actual),
    "regex":    lambda actual, expected: bool(re.search(str(expected), str(actual)))
}
# _evaluate_rule: get user[attribute], if None return False, dispatch to OPERATORS, return False on unknown

  <action>
Run `cd portal && pnpm add vuedraggable@next` to install vuedraggable 4.1.0 (SortableJS wrapper for Vue 3).

Then create `portal/src/composables/useRuleSimulator.ts` — a direct TypeScript port of `_evaluate_rule()` from `backend/app/domains/feature_flags/service.py`. The composable accepts two reactive refs (rules array and contextJson string) and returns `{ matchedIndex, matchedResult, contextError }`.

Implementation rules:
- OPERATORS record must match Python exactly: `equals` uses `===`, `in` checks `Array.isArray(e) && e.includes(a)`, `notIn` checks `Array.isArray(e) && !e.includes(a)`, `contains` uses `String(a).includes(String(e))`, `regex` wraps in try/catch with `new RegExp(String(e)).test(String(a))`
- `evaluateRule()`: get `user[rule.attribute]`; if undefined/null return false; lookup OPERATORS fn; if not found return false; wrap fn call in try/catch returning false
- `useRuleSimulator(rules: Readonly<Ref<RuleSchema[]>>, contextJson: Ref<string>)`: uses `watchEffect` (NOT `watch` with `{ deep: true }`) — watchEffect tracks accessed refs automatically
- On each evaluation: reset all three refs to null, parse contextJson (set contextError if invalid JSON — do NOT clear previous result), iterate rules array first-match-wins
- Return: `{ matchedIndex: Ref<number | null>, matchedResult: Ref<boolean | null>, contextError: Ref<string | null> }`

Import `Ref` and `readonly` from vue. Import `RuleSchema` from `../services/flags`.

The composable directory does not exist yet — create `portal/src/composables/` directory.
