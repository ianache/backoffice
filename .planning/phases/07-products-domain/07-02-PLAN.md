async def update_flag(db: AsyncSession, flag_id: int, payload: FlagUpdate) -> Optional[FeatureFlag]:
    flag = await get_flag(db, flag_id)
    if not flag:
        return None
    data = payload.model_dump(exclude_unset=True)
    for field, value in data.items():
        setattr(flag, field, value)
    await db.commit()
    await db.refresh(flag)
    return flag

- `setattr` each field → `await db.commit()` → `await db.refresh(product)` → return

Implement these endpoints:

**`POST /products`** (`status_code=201`, `response_model=ProductResponse`):
- Parse roles from `x_user_roles: str = Header(...)` header
- Require `PlatformAdmin` role — 403 if missing
- Call `await service.create_product(db, payload)`
- Catch `IntegrityError` → raise `HTTPException(status_code=409, detail=f"Product with id '{payload.id}' already exists")`
- Return created product

**`GET /products`** (`response_model=List[ProductResponse]`):
- Query params: `status: Optional[str] = Query(None)`, `label: Optional[str] = Query(None)`
- No role restriction (any authenticated user via `verify_internal_secret`)
- Call `await service.list_products(db, status=status, label=label)` → return list

**`PATCH /products/{product_id}`** (`response_model=ProductResponse`):
- Parse roles — require `PlatformAdmin` — 403 if missing
- Call `await service.update_product(db, product_id, payload)` → 404 if None
- Return updated product
