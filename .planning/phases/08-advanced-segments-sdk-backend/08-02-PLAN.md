**1. Update backend/app/domains/feature_flags/router.py — segments_router list endpoint:**

The existing GET /flags/segments handler calls list_segments() and returns a list. Update it to unpack (Segment, flag_count) tuples and build SegmentResponse objects with flag_count injected:

```python
@segments_router.get("/", response_model=list[SegmentResponse])
async def list_segments_handler(
    tenant_id: Optional[str] = Query(default=None),
    db: AsyncSession = Depends(get_db),
):
    rows = await service.list_segments(db, tenant_id=tenant_id)
    result = []
    for seg, fc in rows:
        resp = SegmentResponse.model_validate(seg)
        resp.flag_count = fc
        result.append(resp)
    return result
```
