5. Exports `remoteStatuses = reactive<Record<string, 'loaded' | 'error'>>({})` — used by MainLayout nav dimming

6. Shell-only static routes (three entries ONLY — no domain routes):
   - `{ path: '/', redirect: '/stub' }` — redirects root to stub; authenticated users land here
   - `{ path: '/login', component: () => import('../views/LoginView.vue'), meta: { layout: 'auth', title: 'Login' } }`
   - `{ path: '/unauthorized', component: () => import('../views/UnauthorizedView.vue'), meta: { layout: 'main', title: 'Unauthorized', requiresAuth: true } }`

7. Creates router: `export const router = createRouter({ history: createWebHistory(), routes })`

8. Exports `loadMicroUIRoutes()` as named async export:
   - Filters REMOTE_MANIFEST by `!!import.meta.env[remote.envVar]`
   - Maps to async tasks using `Promise.allSettled()`
   - Each task: try `await import(/* @vite-ignore */ \`${remote.name}/routes\`)`, then `mod.default ?? mod.routes ?? []` → forEach `router.addRoute()`, set `remoteStatuses[remote.name] = 'loaded'`
   - Catch: `console.warn(...)`, set `remoteStatuses[remote.name] = 'error'`, `router.addRoute({ path: \`/${remote.pathPrefix}/:pathMatch(.*)*\`, name: \`${remote.name}-error\`, component: RemoteErrorBoundary, meta: { requiresAuth: true, layout: 'main', remoteDisplayName: remote.displayName } })`

9. Auth guard `router.beforeEach` — preserve EXACTLY the existing logic:
   - `if (authStore.isLoading) return true`
   - `if (to.path === '/login' && authStore.isAuthenticated) return { path: '/' }`
   - `if (to.meta.requiresAuth && !authStore.isAuthenticated) return { path: '/login', ... }`
   - Role check: `if (requiredRoles?.length && !requiredRoles.some(r => authStore.hasRole(r))) return { path: '/unauthorized' }`
   - `return true`

10. `export default router`
