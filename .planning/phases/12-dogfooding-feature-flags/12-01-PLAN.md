<objective>
Create the `useBoFlags()` Vue composable that wraps `@backoffice/sdk-js` to evaluate backoffice dogfooding flags (`bo.feature`, `bo.feature.create`, `bo.feature.update`). The composable is a module-scoped singleton with fail-open defaults (`true`), live WebSocket reactivity, and Module Federation exposure for MUI remotes.

Purpose: This is the infrastructure plan that enables UI gating in Plan 12-02. It establishes the SDK dependency, env vars, composable, federation expose, and init point.
Output: Working composable importable from both Shell and `shell/boFlags` federation path; SDK connects to BFF `/sdk/bootstrap` on app boot.
</objective>

<task type="auto">
  <name>Task 3: Create useBoFlags.ts composable</name>
  <files>portal/src/composables/useBoFlags.ts</files>
  <behavior>
    - Module-scoped singleton: `FeatureFlagClient` instance created once across all callers
    - Three `ref<boolean>` with default `true` (fail-open): `boFeature`, `boFeatureCreate`, `boFeatureUpdate`
    - `init(userContext)`:
      1. Guard: if `initialized` is true, return immediately (idempotent)
      2. try: create FeatureFlagClient, await initialize()
      3. Initial evaluate: set refs from `client.evaluate(key, userCtx)`
      4. Hook WS reactivity: override `client.invalidate()` to intercept `flag_updated` — after default invalidation, call `client.evaluateRemote(flagKey, userCtx)` and update the matching ref
      5. Set `initialized = true`
      6. catch: `console.warn()` — refs stay `true`, admin UI never blocked
    - `destroy()`: tears down the SDK client (for SPA unmount / hot reload)
    - Exported function `useBoFlags()` returns `{ boFeature, boFeatureCreate, boFeatureUpdate, initialized, init, destroy }`
  </behavior>
  <action>
    Create `portal/src/composables/useBoFlags.ts` with the implementation described above.

    Key implementation detail for WS reactivity:
    ```typescript
    // After client.initialize(), monkey-patch invalidate to trigger re-eval
    const originalInvalidate = client.invalidate.bind(client)
    client.invalidate = (flagKey: string) => {
      originalInvalidate(flagKey)
      // Re-fetch from remote and update ref
      client.evaluateRemote(flagKey, userCtx).then(result => {
        updateRef(flagKey, result)
      }).catch(() => { /* fail-open: keep current value */ })
    }
    ```

    The `updateRef` helper maps flag key to the corresponding ref:
    ```typescript
    const FLAG_MAP: Record<string, Ref<boolean>> = {
      'bo.feature':        boFeature,
      'bo.feature.create': boFeatureCreate,
      'bo.feature.update': boFeatureUpdate,
    }
    function updateRef(flagKey: string, value: boolean) {
      const r = FLAG_MAP[flagKey]
      if (r) r.value = value
    }
    ```
  </action>
  <done>useBoFlags.ts exports a singleton composable with fail-open defaults, SDK init, and WS-driven reactivity.</done>
</task>
