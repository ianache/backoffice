<objective>
Wire the `useBoFlags()` composable refs into the 4 UI touch-points that Phase 12 gates:
1. MainLayout sidebar — Feature Flags + Segments nav items → `boFeature`
2. FlagsView — Create Flag button → `boFeatureCreate`
3. FlagTable — Edit pencil → `boFeatureUpdate`, Clone button → `boFeatureCreate`

All changes are purely template-level `v-if` bindings plus a composable import in `<script setup>`. No logic changes, no new components.

Purpose: With Plan 12-01's composable in place, this plan adds the actual v-if gating that makes the UI respond to feature flag state.
Output: All 4 UI elements are conditionally rendered based on the SDK-evaluated flag values, with fail-open behavior preserved.
</objective>
