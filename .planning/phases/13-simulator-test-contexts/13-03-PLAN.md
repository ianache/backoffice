<objective>
Extend `RuleSimulator.vue` — currently a single-prop (`rules`) component mounted only in `RuleBuilderView.vue` — into the shared, persistent Live Simulator described by SIM-02/SIM-03: it now accepts a saved `testContext` and a `mode` ('flag'|'segment'), recovers the saved context on open (falling back to the existing synthetic placeholder), offers an explicit "Save Test Context" button gated on JSON validity, and a "use my real context" toggle that swaps in the logged-in user's real attributes (read-only, live re-evaluated) without any new evaluation logic.

Purpose: This is the core UI change for Phase 13 — both `RuleBuilderView.vue` (flags) and `SegmentForm.vue` (rule-based segments) will mount this same component in Plan 13-04. Building it here as a self-contained, prop/emit-driven component lets Plan 13-04 wire it without touching simulator internals.
Output: `RuleSimulator.vue` with `props: { rules, mode?, testContext? }`, `emits: ['save-test-context']`, real-context toggle backed by `shell/useUserContext`. `flags.ts` types extended with `test_context`.
</objective>

    1. In `RuleSimulator.vue`, add the real-context toggle logic in `<script setup>`:
       ```typescript
       import { useUserContext } from 'shell/useUserContext'

       const useRealContext = ref(false)
       let previousContextJson = ''

       const realContextJson = computed(() => {
         const ctx = useUserContext()
         return JSON.stringify(
           {
             sub: ctx.sub,
             email: ctx.email,
             roles: ctx.roles,
             tenant_id: ctx.tenant_id,
             product_id: ctx.product_id,
           },
           null,
           2,
         )
       })

       function toggleRealContext(): void {
         if (!useRealContext.value) {
           // Turning ON — save current value, switch to real context
           previousContextJson = contextJson.value
           contextJson.value = realContextJson.value
           useRealContext.value = true
         } else {
           // Turning OFF — restore previous value
           contextJson.value = previousContextJson
           useRealContext.value = false
         }
       }
       ```
