Locked anyOf semantics (CONTEXT.md):
- `value` is ALWAYS a real JSON array (UI parses comma text to array on save — Plan 14-04).
- context attribute is a LIST → match if intersection with value is non-empty.
- context attribute is SCALAR → match if it is a member of value.
- Case-sensitive, no normalization in the operator (trim happens at UI parse time).
- Additive: `in`, `notIn`, `contains` untouched.

Python lambda (both backend service.py and sdk-python evaluator.py — identical):
```python
'anyOf': lambda actual, expected: (
    bool(set(actual) & set(expected)) if isinstance(actual, (list, tuple, set))
    else actual in expected
),
```
(unhashable elements raise → caught by the existing _evaluate_rule try/except → False, fail-closed)

TypeScript (sdk-js evaluator.ts; same function reused verbatim in Plan 14-04 for useRuleSimulator.ts):
```typescript
anyOf: (actual, expected) => {
  if (Array.isArray(actual)) {
    const expectedArr = Array.isArray(expected) ? expected : []
    return actual.some((v) => expectedArr.includes(v))
  }
  return Array.isArray(expected) && expected.includes(actual)
},
```
