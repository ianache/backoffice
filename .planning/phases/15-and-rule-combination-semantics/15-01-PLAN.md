- `mode = rule_combination_mode or 'first_match'` (NULL/missing/empty => legacy).
- mode == 'and' AND rules is non-empty:
  - ALL rules match (`_evaluate_rule` per rule, existing fail-closed semantics) => return True.
  - Any rule fails => return False immediately. Do NOT consult per-rule `result`, do NOT fall through to segment membership, do NOT return default_val. (Planner decision under CONTEXT.md discretion, honoring the user's literal "other case the result is false". Segments/default_val remain reachable only when the rules list is empty.)
- mode == 'and' AND rules is empty: behave exactly like today's no-rules path (segment check, then default_val) — vacuous AND must not change legacy no-rules flags.
- mode == 'first_match' (or NULL): existing behavior byte-identical — first matching rule returns `bool(rule.get('result', winner.default_val))`, then segments, then default_val.
