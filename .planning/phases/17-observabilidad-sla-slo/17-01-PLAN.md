<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backend → BFF / Keycloak | Backend health checker makes outbound HTTP pings to configured internal URLs |
| health checker → service_health_samples | Background task writes error strings (details) that may surface in metrics |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-01 | Tampering / Info Disclosure | _check_bff / _check_keycloak URLs | accept | URLs are hardcoded config values (settings.bff_internal_url, settings.keycloak_url), never user-supplied — no SSRF surface |
| T-17-02 | Info Disclosure | details field on DOWN | mitigate | Store str(e) (not repr(e)); truncate details to 500 chars in health_checker.py before write |
| T-17-03 | Denial of Service | startup cascade if first check fails (MySQL not ready) | mitigate | Per-check try/except + per-iteration body wrap; an uncaught exception must never exit the while loop or block lifespan (Pitfall 1) |
| T-17-SC | Tampering | pip installs | accept | No new pip packages in this plan (httpx, sqlalchemy, fastapi already installed) — no package-legitimacy gate needed |
</threat_model>
