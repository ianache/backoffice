Create `bff/src/routes/labels.ts`, near-identical to `bff/src/routes/flags.ts` but adding `UXWriter` to the allowed roles (per PRD §4: UXWriter has access to the labels module for value edits, even though it cannot do structure CRUD — backend enforces the finer-grained restriction on `/keys/{id}/value` vs other endpoints):

```typescript
import { Router } from 'express'
import { createProxyMiddleware } from 'http-proxy-middleware'
import { requireAuth } from '../middleware/auth.js'
import { requireRole } from '../middleware/roles.js'
import { config } from '../config/index.js'

export const labelsRouter = Router()

labelsRouter.use(
  requireAuth,
  requireRole('PlatformAdmin', 'TenantAdmin', 'TenantOwner', 'ProductManager', 'UXWriter'),
  createProxyMiddleware({
    target: config.backendUrl,
    changeOrigin: true,
    // Express strips the '/labels' mount prefix from req.url before passing to this
    // middleware, so we must add it back so the backend sees the correct path.
    pathRewrite: (path) => `/api/v1/labels${path}`,
    on: {
      proxyReq: (proxyReq, req) => {
        proxyReq.setHeader('X-Internal-Secret', config.internalSecret)
        proxyReq.setHeader('X-User-Sub', (req as any).user?.sub ?? '')
        proxyReq.setHeader('X-User-Roles', ((req as any).user?.roles ?? []).join(','))
        proxyReq.setHeader('X-User-Tenant-Id', (req as any).user?.tenantId ?? '')
        proxyReq.setHeader('X-User-Email', (req as any).user?.email ?? '')
      },
    },
  })
)
```

Note the `pathRewrite` here is `/api/v1/labels${path}` (not `/labels${path}` like flags.ts) because the backend `labels` router is mounted at `/api/v1/labels` (per 20-03's `app.include_router(labels_router, prefix="/api/v1")` where `router = APIRouter(prefix="/labels", ...)`), whereas `flags.ts` rewrites to `/flags${path}` because the backend flags router is mounted directly without the `/api/v1` prefix (or with a different convention — VERIFY by checking `backend/app/main.py`'s actual include_router call for `flags_router` vs `labels_router` and match each BFF route's pathRewrite to its backend's real mount path exactly).
