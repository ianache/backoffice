<threat_model>
### T-21-02: Label infrastructure blocks unauthenticated access
- **Threat:** A hung bootstrap request, bad SDK key, BFF outage, or SDK exception prevents the login from rendering.
- **Severity:** HIGH
- **Mitigation:** Race the initialization promise against a 1-second deadline, swallow/log failures, and retain bundled fallbacks.
- **Verification:** Fake-timer unit tests prove the deadline resolves and login mount can continue on pending/rejected initialization.

### T-21-03: Missing labels expose diagnostics or trigger duplicate connections
- **Threat:** Users see `[sys.key]`, or repeated init creates duplicate WebSockets/missing reports.
- **Severity:** MEDIUM
- **Mitigation:** One module-scoped idempotent client; fallback-aware translation calls SDK once then substitutes the sentinel.
- **Verification:** Unit tests assert one client, one initialize call, fallback output, and late reactive update.
</threat_model>
