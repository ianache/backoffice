- **Severity:** HIGH
- **Mitigation:** Auth store throws stable internal error codes; view maps known codes to approved login label keys and everything else to `login.error_generic`.
- **Verification:** Unit tests prove unknown/raw messages never become display copy.

- **Threat:** Late hydration or WebSocket invalidation remounts the form, clearing password/focus/open/loading state.
- **Severity:** MEDIUM
- **Mitigation:** Replace text bindings only; preserve existing component/DOM/state structure and keys.
- **Verification:** Browser test changes translation response after interaction and asserts values/open form remain intact.
</threat_model>
